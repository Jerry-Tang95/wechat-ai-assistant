# 微信AI助手（wechat-ai-assistant）

PC 微信 4.x 的消息监控 + AI 自动回复工具。基于 pywinauto UI 自动化（无 hook、无协议逆向），本地运行，数据不出本机。

## 功能

- **三种角色，同一个微信号**
  - **白名单客户自动回复**：规则话术优先直发，未命中走大模型（LLM）生成直发
  - **群消息监控**：关键词命中 → 控制台提醒（可配关键词自动回复）
  - **AI 分身**：其余私聊由 LLM 生成草稿 → 本地控制台人工审核后发送（可切自动直发）
- **实时数据工具层**：LLM 答不了的"今天天气/几点了/搜一下"自动调免费数据源（Open-Meteo / 本机时钟 / DuckDuckGo），把真实数据注入 prompt 再由 LLM 组织回复
- **人设范围门禁**：人设限定了业务范围时（如"只答颌面外科咨询"），范围外的问题自动拒绝，不会被工具数据带跑
- **安全兜底**：转人工关键词自动挂起、敏感词转草稿、工作时段/频控/每日上限、会话去重防重复回复
- **监控零干扰**：空闲时只读扫描会话列表（未读徽标 + 消息预览），不点击不抢焦点；仅发送时操作微信窗口
- **本地 Web 控制台**：消息流、待审草稿一键审核、群提醒、表单化配置（热生效），单文件页面

## 环境要求

- Windows 10 / 11（64 位）
- Python 3.12（[官网下载](https://www.python.org/downloads/)，安装时勾选 Add to PATH）
- 微信 PC 版 **4.1.x** 已登录（本项目在 4.1.15.13 实测）
- ⚠️ 微信 4.1+ 收紧了无障碍策略：**账号需曾开启过无障碍/讲述人模式，UI 自动化树才可见**。新号可能无法使用。先跑 `probe_ui_tree.py` 验证（只读、无风险）

## 快速开始

```bat
git clone https://github.com/<你的用户名>/wechat-ai-assistant.git
cd wechat-ai-assistant
pip install -r requirements.txt

:: 配置：复制模板并填入 API key（智谱 https://open.bigmodel.cn 注册即得，glm-4-flash 免费）
copy app\config.example.json app\config.json
:: 编辑 app\config.json 填入 llm.api_key

:: 启动（微信需已登录、主窗口停留在「聊天」页）
启动微信AI助手.bat
```

控制台自动打开 `http://127.0.0.1:8765`，在「监控对象设置」表单里填客户备注名/群名，保存即热生效。

**测试模式**：`启动微信AI助手.bat --mock`（不碰真微信，用控制台「Mock 注入」验证全流程）。

## 工作原理

```
会话列表(只读扫描: 未读徽标+消息预览+行内时间)
        │ 去重键=(行内时间,预览)，未读数增加辅助触发
        ▼
   引擎分流 ──┬─ 白名单客户 ── 规则话术直发 / LLM 生成直发
              ├─ 群监控     ── 关键词 → 控制台提醒
              └─ AI 分身    ── LLM 草稿 → 人工审核 → 发送
        │
   工具层(天气/时钟/搜索) ──人设范围门禁──> 真实数据注入 prompt
        │
   GLM(免费档) 生成回复 ──> 去Markdown/微信体纪律 ──> UI自动化发送
```

- 底层：[pyweixin](https://github.com/Hello-Mr-Crab/pywechat)（LGPL-2.1，锚定实测 commit）
- 私聊气泡无发送人前缀且控件树不稳定，故**不读聊天气泡**，只读会话列表——未读徽标只在对方来讯时增加，发送人归属天然正确
- 发送前先点击会话定位并校验顶部聊天名，杜绝发错人
